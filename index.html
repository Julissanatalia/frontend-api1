TV Explorer API

Portal de Consumo Frontend

📚 Guía Teórica: Consumo de APIs

Este portal utiliza la Fetch API nativa de JavaScript para realizar peticiones HTTP asíncronas (GET) a la API pública de TVMaze. Los datos, recibidos en formato JSON, se procesan mediante promesas (async/await) para inyectar y renderizar dinámicamente el DOM, implementando además un medidor de latencia en la respuesta.
